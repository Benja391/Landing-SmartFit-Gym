# 🏋️‍♂️ Landing SmartFit Gym

Landing page moderna y responsiva del mundo fitness, diseñada para destacar la marca, atraer nuevos clientes y mostrar los servicios principales del gimnasio.

---

## 📌 Descripción

Este proyecto es una landing page estática que simula el sitio web de un gimnasio icónico. Está enfocada en diseño visual, estructura clara y compatibilidad con distintos dispositivos.

---

## 🛠️ Tecnologías utilizadas

- **HTML5**: estructura semántica
- **CSS3**: estilos personalizados y responsivos
- **Boostrap**: estilos generales
- **JavaScript**: interacciones básicas
- **Diseño responsivo**: adaptable a móviles y escritorio
